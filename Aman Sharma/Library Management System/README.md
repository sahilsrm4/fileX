# Library Management System

A menu-driven Library Management System built in Python using Object-Oriented Programming (OOP). The application manages books and users, supports borrowing and returning operations, maintains borrowing history, and persists library data using JSON.

## 1. Project Description

The Library Management System is a command-line application designed to manage the day-to-day operations of a library.

The system allows users to:

- Manage books
- Manage library users
- Search for books
- Borrow and return books
- View available and borrowed books
- View borrowing history
- Save and load library data using JSON

The application also supports automatic persistence. Existing data from `library.json` is loaded when the application starts, and important changes are automatically saved to the same file.

## 2. Implemented Features

- Add a new book
- Remove a book
- Search books by Book ID, Title, or Author
- Add a new user
- Remove a user
- Borrow a book
- Return a book
- Enforce the maximum borrowing limit for users
- Prevent borrowing an unavailable book
- Prevent removal of a borrowed book
- Prevent removal of a user with borrowed books
- View available books
- View borrowed books
- View borrowing history
- Save library data to a JSON file
- Load library data from a JSON file
- Automatically load `library.json` when the application starts
- Automatically save changes after important library operations
- Handle library-related errors using custom exceptions

## 3. How to Run the Application

### Prerequisites

Python must be installed on the system.

Verify the Python installation:

```bash
python --version
```

### Run the Application

Navigate to the project directory:

```bash
cd "E:\Library Management System"
```

Then run:

```bash
python main.py
```

The application will display the main menu:

```text
========================================
       LIBRARY MANAGEMENT SYSTEM
========================================
1. Add Book
2. Remove Book
3. Search Book
4. Add User
5. Remove User
6. Borrow Book
7. Return Book
8. View Available Books
9. View Borrowed Books
10. View Borrowing History
11. Save Library
12. Load Library
0. Exit
========================================
```

If `library.json` exists in the project directory, its saved data will automatically be loaded when the application starts.

## 4. Required Packages

No external third-party packages are required.

The project uses Python's built-in modules:

- `json` - Used to save and load library data in JSON format.
- `os` - Used to check whether `library.json` exists before automatic loading.

Therefore, no `pip install` command is required.

## 5. Known Limitations

- Borrowing history records the book, borrower, and action, but does not store timestamps.
- The application is intended for a simple local library-management use case and does not include advanced features such as authentication, role-based access, or multi-user concurrency.
- The application expects `library.json` to follow the data structure generated by the system.
